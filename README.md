# Actividad Unidad V - To Do Backend

## Instalación

npm install

## Configuración

Crear archivo .env

MONGO_URI=mongodb://127.0.0.1:27017/todolist
PORT=3000

## Ejecutar

npm start

## Endpoints

GET /getTasks
GET /getGoals

POST /addTask
POST /addGoal

DELETE /removeTask/:id
DELETE /removeGoal/:id
