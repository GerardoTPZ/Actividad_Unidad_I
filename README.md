# Actividad 4 - Backend To Do List

Aplicación backend desarrollada con Node.js y Express para gestionar tareas y metas personales.

Incluye:

- Gestión de tareas
- Gestión de metas
- Middleware con API KEY
- Validaciones de parámetros
- Códigos de respuesta HTTP:
  - 200 OK
  - 400 Bad Request
  - 401 Unauthorized

- Se incluye la Carpeta POSTMAN para probar las pruebas HTTP
  Importar en Postman:
    1. Abrir Postman
    2. Click en "Import"
    3. Seleccionar el archivo

# Tecnologías utilizadas

- Node.js LTS
- Express.js
- Cors
